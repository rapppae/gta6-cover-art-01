Vice City Cover Maker turns any photo into multi-panel GTA 6-style cover art — pick a 2, 3 or 4-panel layout, crop and position each photo, write a bold caption, and export it as a PNG in 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
